这是一个**荒岛求生主题的生存策略游戏**，主要功能包括：

### 核心玩法
1. **物资合成系统**：通过拖拽将两个物资合成更高级的物资（1-4级），包括原材料、食物、工具三大类
2. **行动系统**：执行四种行动
   - **寻找物资**：在不同地点（树林、海边、山洞）寻找原材料
   - **制作工具**：用原材料制作各种工具
   - **打猎/钓鱼/砍伐**：使用工具获取食物或原材料（工具等级越高，消耗体力越少）
   - **修建庇护所**：加固庇护所提高坚固值
   - **进食**：消耗食物恢复生存状态和行动点

3. **挑战系统**：7天内完成4个递进式挑战，每个挑战有特定目标（如收集特定物资、达到特定等级等）

4. **天气系统**：动态天气影响行动成功率，恶劣天气下行动有30%失败率，但成功时获得双倍收益

5. **生存数值管理**：
   - 生存状态值（0-100）：通过进食恢复，行动会消耗
   - 庇护所坚固值（0-100）：通过修建庇护所提升
   - 行动点系统：每天有限行动点，消耗后需等待下一天

### AI增强功能
- **AI生成图片**：为各种行动和场景生成对应的插画图片
- **AI生成描述**：为合成、行动等生成生动的文字描述
- **AI生成结局**：根据玩家表现生成个性化结局总结

### 特色功能
- **拖拽式操作**：直观的拖拽界面进行合成和行动
- **实时挑战检查**：完成挑战条件后立即结算奖励
- **地点解锁**：通过特定物资解锁新地点
- **角色形象生成**：游戏开始时可生成个性化角色形象
